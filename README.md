# Түлектерге 20 жыл · 25 мамыр 2027

Приложение для подготовки к встрече одноклассников (выпуск 2007, Актау). Основной язык — казахский, справа вверху переключатель **ҚАЗ / РУС** (выбор запоминается). Работает на телефоне как обычное приложение (PWA).

## Что внутри

- **Басты** — «20», дата, обратный отсчёт, статистика класса (парни/девушки), ход подготовки.
- **Сынып** — 20 одноклассников, фильтр парни/девушки; нажатие на своё имя — вход как этот человек, рядом с именем виден ответ на «Келесіз бе?».
- **Сауал** — 10 опросов с живыми результатами (дата, сколько дней, место, взнос, программа, темы квиза и др.).
- **Идеялар** — свободные идеи с лайками.
- **Жоспар** — сценарий дня, подготовка по срокам, калькулятор бюджета.
- **Ұстаздар** — список учителей, который класс заполняет сам.
- **Афиша** — квиз (ответственный Наурызбек Ерманов, класс присылает темы и вопросы) вечер гитары (Мәлік, Бағдат, Медет, Өркен, Кенжебек; класс предлагает песни) и блок «Пожелания», где каждый предлагает свой номер программы (караоке, танцы и т. д.).
- **Музыка** — на главной, под линией: две отдельные кнопки «1-музыка · Магнитола» (`song1.mp3`) и «2-музыка · Школа» (`song.mp3`). Нажатие включает песню (она повторяется), повторное — пауза. Полоса перемотки видна только пока музыка играет.

## Публикация (GitHub Pages)

Settings → Pages → Deploy from a branch → **main** / **(root)** → Save. Сайт: `https://aura2889.github.io/20_zhyl/`.
Установка на телефон: Android — Chrome → «Добавить на главный экран»; iPhone — Safari → «Поделиться» → «На экран Домой».

## Общие голоса

**Сейчас подключён Firebase Realtime Database** (`const DB_URL = "https://class20-f031a-default-rtdb.firebaseio.com/";` в `index.html`). Правила базы: `{"rules":{".read":true,".write":"now < 1814313600000"}}` (запись открыта до 30 июня 2027). Проверка: вкладка «Сауал» → **🔧 Базаны тексеру**.

Запасной вариант без Firebase — Google Таблица (если пустой `DB_URL`, используется `GAS_URL`):

GitHub Pages не хранит данные, поэтому общие голоса лежат в Google Таблице, а сайт общается с ней через небольшой скрипт Google (`apps-script/Code.gs`). Пока адрес скрипта не вписан, приложение работает в **демо-режиме** (голоса видны только на своём телефоне).

1. Создайте новую Google Таблицу (например, «20 жыл база»).
2. **Расширения → Apps Script**. Удалите всё, что там есть, вставьте содержимое `apps-script/Code.gs`, нажмите **Сохранить**.
3. **Развернуть → Новое развертывание → тип «Веб-приложение»**: *Выполнять от имени* — **я**, *У кого есть доступ* — **Все** (Anyone). Нажмите **Развернуть** и разрешите доступ (Google покажет предупреждение «приложение не проверено»: **Дополнительно → Перейти → Разрешить**).
4. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и вставьте в `index.html` вместо `const GAS_URL = "";`, затем Commit.
5. Откройте сайт → вкладка «Сауал» → **🔧 Базаны тексеру**: все пункты должны быть с галочкой.

Каждый ответ хранится отдельной строкой листа `data` (путь | значение | время): таблицу можно открыть и выгрузить. Запись идёт под блокировкой, поэтому одновременные голоса не затирают друг друга. Если позже изменить код скрипта, нужно сделать **Развернуть → Управление развертываниями → ✏ → Новая версия**.

Почему не jsonblob: он читается с сайта, но браузер блокирует запись (PUT). Альтернатива — Firebase Realtime Database (`const DB_URL = "";`), но для него Google требует двухэтапную проверку; правила: `{"rules":{".read":true,".write":"now < 1814313600000"}}`.

## Что менять в файле

В `index.html` в начале скрипта: `CLASSMATES` (список), `POLLS` (опросы), `PLAN_DAY` и `CHECK` (план), `GUITAR` (гитаристы), `QUIZ_BOSS` (ответственный за квиз), `TRACKS` (песни), `GAS_URL` (адрес базы). Тексты заданы парами `[казахский, русский]`.

## Ограничения

Закрытое приложение для друзей без паролей: любой, у кого есть ссылка, может выбрать чужое имя. Не публикуйте ссылку в открытых группах. Казахский перевод сделан без носителя-редактора; стоит попросить одноклассника пробежать глазами.
