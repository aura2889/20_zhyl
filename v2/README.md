# 20 лет выпуска · 25 мая 2027 (версия на русском, папка v2)

Приложение для подготовки к встрече одноклассников (выпуск 2007, Актау): список класса, план встречи, опросы с живыми результатами, свободные идеи и список учителей. Работает на телефоне как обычное приложение (PWA).

## Публикация (GitHub Pages)

1. Репозиторий → **Settings → Pages**.
2. **Source:** Deploy from a branch → **main** / **(root)** → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://aura2889.github.io/20_zhyl/v2/`.
4. Установка на телефон: Android — Chrome → «Добавить на главный экран»; iPhone — Safari → «Поделиться» → «На экран Домой».

## Общая база голосов (обязательно один раз)

GitHub Pages — статический хостинг, он не хранит голоса. Пока база не подключена, приложение работает в **демо-режиме**: голоса видны только на том телефоне, где их поставили. Чтобы все видели общие результаты, подключите бесплатную базу Firebase Realtime Database (карта не нужна):

1. Откройте https://console.firebase.google.com → **Add project** (имя любое, Google Analytics отключить).
2. В проекте: **Build → Realtime Database → Create Database**. Регион — любой (например, `europe-west1`). Режим — **Start in test mode**.
3. Вкладка **Rules** → замените содержимое на правила ниже → **Publish**:

```json
{
  "rules": {
    ".read": true,
    ".write": "now < 1814313600000"
  }
}
```

   Запись разрешена до 30 июня 2027, после этого база станет «только для чтения» и её нельзя будет испортить.
4. Вкладка **Data** — скопируйте адрес базы вида `https://имя-проекта-default-rtdb.europe-west1.firebasedatabase.app`.
5. В файле `index.html` найдите строку `const DB_URL = "";` и вставьте адрес между кавычками. Сохраните и закоммитьте.

После этого голоса, идеи, лайки и список учителей общие для всех, а страница сама обновляется каждые 25 секунд.

## Как это устроено

- Один человек — один голос: при первом входе выбираете своё имя из списка класса (или «гость» для учителей и родных).
- Список класса, опросы и план редактируются прямо в `index.html`: массивы `CLASSMATES`, `POLLS`, `PLAN_DAY`, `CHECK`.
- Файлы: `index.html`, `manifest.json`, `sw.js` (работа без сети), `icon-192.png`, `icon-512.png`.

## Ограничения

Это закрытое приложение для друзей, без паролей: любой, у кого есть ссылка, может выбрать чужое имя. Для опроса среди одноклассников этого достаточно; не публикуйте ссылку открыто.
